# Nothing checks the verdict against the evidence

`wayfinder:grilling` · OPEN · blocked by: A1

## Question

Advocates are checked (arithmetic, citations, scores, defects). The VERDICT is
not. It is generated by the judge and returned, and no step asks whether the
final text is consistent with the reference material it was built from.

The previous effort fixed three separate cases of a defect being caught upstream
and surviving into the answer anyway. The pattern is strong enough to justify a
last gate.

To decide:
- Deterministic: run `_check_arithmetic` and `_check_citations` over the VERDICT
  too, not only over advocate answers. Nearly free, and directly catches the class
  of bug that keeps recurring. Note the verdict has no CALC lines, so arithmetic
  checking would need the judge to emit them — decide whether that is worth it.
- One cheap model call asking only "does this answer state anything the reference
  material contradicts" — a narrow question a small model can do, unlike grading.
- Or nothing: argue that after the upstream fixes the residual risk is small, and
  a fourth checkpoint costs more than it saves. Take this option seriously; the
  cost discipline in the map Notes is real.
