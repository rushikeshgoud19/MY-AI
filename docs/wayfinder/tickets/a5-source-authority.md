# Prefer sources that can actually carry the fact

`wayfinder:grilling` · OPEN · blocked by: A1, A2

## Question

The judge can now SEE the sources and penalises a claim built on the wrong one —
proven when probe 7's 7900XTX-forum answers fell 9→4 and 8→3. But that is damage
control at scoring time. The bad source still entered the block and still shaped
four answers; the panel spent a whole debate reasoning from a consumer-GPU forum
thread.

Should selection happen earlier, at fetch time?

- Prefer official/primary domains for the fact TYPE being asked: a vendor's own
  docs for pricing, a spec for a limit. Requires knowing which domain is primary,
  which is easy for named products and hard in general.
- Rank hits by whether the extract contains the SHAPE of the wanted fact (currency
  symbol, a unit, a version number) when the query asks for one. Cheap and
  deterministic, and it would have preferred the pricing page over the valuation
  story.
- Risk, stated in the old map and still true: irrelevant grounding is worse than
  none, but so is a filter that discards the one good hit. Any ranking must be
  measured on the A1 eval, not reasoned about.
